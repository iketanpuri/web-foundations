02 / FINDING THE ADDRESS

Names for people.
Addresses for computers.

DNS, the Domain Name System, helps translate a domain into the address needed to reach its server. It is a distributed lookup system, with caching that often makes repeat visits faster.

01 — RECURSIVE RESOLVER

Your lookup assistant.

Checks its cache. If necessary, asks other DNS servers to find the requested record.

02 — ROOT & TLD

The directions.

Root servers point toward TLD servers, such as those for .com. TLD servers identify the domain’s authoritative servers.

03 — AUTHORITATIVE

The source of the record.

Returns the domain’s DNS records. The resolver can cache them for their configured time to live.

THE LOOKUP, SIMPLIFIED

From name to connection.

example.com → cache / resolver → authoritative record → IP address → web server.

DNS finds the address. HTTPS then connects the browser to the website securely. A cached result can skip much of the lookup.

THE UPSIDE

Shared resources.

Centralized management, controlled access, consistent updates and shared services make client–server systems practical for many users.

THE TRADE-OFF

Plan for resilience.

Servers require maintenance. High traffic and outages affect availability, so systems often use replication, load balancing and caching.
