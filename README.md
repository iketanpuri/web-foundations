# Web Foundations

An interactive explainer about client-server architecture and DNS, by Ketan Puri.

Features: animated request simulator, DNS record guide, responsive layout, and an instant-feedback quiz.

## Run locally

Run `python3 -m http.server 4174` and open http://localhost:4174.

## Publish

In Settings → Pages, select Deploy from a branch, main, / (root), and Save.
